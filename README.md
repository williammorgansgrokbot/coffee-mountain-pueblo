# Coffee Mountain: Pueblo Edition · Café de la Montaña

Play it here: https://williammorgansgrokbot.github.io/coffee-mountain-pueblo/

This is a separate edition of [Coffee Mountain](https://williammorgansgrokbot.github.io/coffee-mountain/). The original game is unchanged.

What's different in the Pueblo Edition:
- The villages are built from procedural 3D Honduran adobe houses. They have clay-tile roofs, porches, colored walls, chimneys, laundry lines, flower pots and bougainvillea. There is also a 3D wet mill with drying patios, a coffee co-op, and a summit chapel with a bell.
- Road clearance logic keeps every building footprint off the trails. Each house faces the nearest road. Trees and buildings fade out when they are between the camera and a donkey.
- The plazas and door paths are cobbled. Window glow and street lamps light the villages at night.

It is one standalone offline HTML file (index.html). It works in desktop browsers, the Tesla browser, and iPhone Safari 13+. Saves use the `cmp_` prefix, so they stay separate from the original game.
